# V2.2-V2.7 Operator Workbench Construction Record

This record closes the post-V2.1 operator-experience tranche. It does not claim new Agent runtime support. The goal was to make existing runtime evidence, subscription delivery diagnostics, and forwarding diagnosis easier to act on from the first screen of each core workspace.

## Scope

V2.2-V2.7 focused on one cross-cutting improvement: a shared Operator Workbench layer for Xray customer nodes, Subscription delivery, and Forwarding operations.

The UI/UX direction came from `ui-ux-pro-max`: dense operations dashboard, semantic state colors, accessible controls, small but clear action targets, and copyable support packages. The implementation uses real read models and diagnosis helpers instead of demo-only state.

## Implemented

- Added `OperatorWorkbenchPanel` as a shared layout component for cross-feature operations triage.
- Added tokenized CSS states for `ready`, `attention`, `waiting`, and `blocked`.
- Added Xray customer-node triage for runtime failures, policy risk, shared inbound density, and subscription delivery gaps.
- Added Subscription delivery triage for blocked identities, identities needing review, source sync issues, and inventory match gaps.
- Added Forwarding operations triage for runtime issues, waiting apply/release state, port conflicts, and Agent-runtime blocked controls.
- Added safe copyable diagnostic packages:
  - `ou-ui-next.xray-operator-workbench.v1`
  - `ou-ui-next.subscription-operator-workbench.v1`
  - `ou-ui-next.forwarding-operator-workbench.v1`
- Added tests for the shared component and page-level visibility on Nodes, Subscription, and Forwarding.

## Sanitization Boundary

The copied diagnostic packages intentionally include IDs, names, counts, states, reasons, diagnosis stage, and non-secret routing hints. They intentionally exclude:

- client credentials
- raw subscription tokens
- token hashes
- full public subscription URLs
- source URLs
- raw command payloads
- full runtime artifact bodies
- runtime snapshot state bodies
